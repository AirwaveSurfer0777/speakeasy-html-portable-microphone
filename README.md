# SpeakEasy

A real-time web-based audio streaming application that allows users to capture microphone input and project it through speakers. Built with modern web technologies and featuring Bluetooth connectivity options.

## Features

- Real-time audio capture and playback
- Low-latency audio processing
- Bluetooth device connectivity support 
- Modern, responsive UI with Tailwind CSS
- Simple controls for start/stop functionality

## Technologies Used

- Web Audio API
- Web Bluetooth API
- Tailwind CSS
- Font Awesome Icons
- Google Fonts (Roboto)

## Prerequisites

A modern web browser that supports:
- Web Audio API
- Web Bluetooth API (for Bluetooth functionality)
- JavaScript ES6+
